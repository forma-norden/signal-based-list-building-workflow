# CLAUDE.md - signal-based-list-building-workflow

This repo defines signal-first list-building workflows for B2B GTM teams.

## Skills in This Repo

| Skill | When to use it |
|-------|---------------|
| `signal-hiring-intent-capture` | sourcing and scoring list rows from hiring events |
| `signal-visitor-identification` | converting anonymous website activity into route-ready accounts and contacts |
| `signal-linkedin-engagement-capture` | operationalizing LinkedIn engagement into outbound-ready data |
| `signal-tech-stack-qualification` | qualifying by stack presence, absence, and adjacent gaps |
| `signal-funding-trigger-monitor` | ranking funded-account signals by urgency and fit |
| `signal-source-prioritizer` | sequencing sources by expected pipeline yield and execution cost |

## Output Rule

Every output must include:

- signal score or confidence
- qualification and disqualification logic
- route recommendation
- first action and owner

## Testing Rule

Run tests from the `tests/` folder before production use.
